## Distributed Container Images

Model Atlas publishes runtime images to Docker Hub and the GitHub Container
Registry:

* `docker.io/eclipsefennec/model.atlas:apicurio-latest` / `:apicurio-snapshot`
* `docker.io/eclipsefennec/model.atlas:file-latest` / `:file-snapshot`
* `ghcr.io/eclipse-fennec/model.atlas` (mirrored tags)

These images bundle third-party content that retains its original license.
